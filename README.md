# web-vaccine-tracker

> **Deprecated / archived.** The domain (COVID vaccination tracker) is over and
> the repository is kept as a historical portfolio piece. The toolchain is EOL
> (`react-scripts@4` + CRACO 6 + Material UI v4-alpha) and carries known
> vulnerabilities in its dependencies; **installing or running the app is not
> recommended**. No patches will be applied on this stack: bringing it up to date
> would amount to a greenfield rewrite (Vite + React 19 + MUI v7). The
> instructions below are kept for historical reference only.

## Running the project

Same as for any project in general: download it and run

### `npm install`

Then

### `npm start`

This runs the app, probably on port 3000. So open your browser and go to:

[http://localhost:3000](http://localhost:3000)
